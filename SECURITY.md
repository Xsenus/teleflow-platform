# Политика безопасности

Не публикуйте сведения об уязвимости в открытом issue.

Передайте владельцу репозитория минимальный воспроизводимый пример, затронутую версию,
оценку влияния и предлагаемый способ исправления через приватный канал организации или
GitHub Private Vulnerability Reporting, если он включён для репозитория. Не прикладывайте
реальные токены, Telegram session, персональные данные или production-архивы.

Поддерживается текущая версия из `pyproject.toml`. Исправления безопасности выпускаются
для неё; поддержка старых версий определяется владельцем развёртывания отдельно.

Архитектурная модель угроз, правила секретов и процедуры реагирования описаны в
[`docs/SECURITY.md`](docs/SECURITY.md) и
[`docs/INCIDENT_RESPONSE.md`](docs/INCIDENT_RESPONSE.md).
